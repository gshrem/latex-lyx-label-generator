# Support – LaTeX & LyX Label Generator

For help, bug reports, questions, or suggestions, use the public [GitHub Issues page](https://github.com/gshrem/latex-lyx-label-generator/issues). You can also browse existing reports there.

Please include a short description of your request and, if relevant, a minimal example showing the label you expected and the label you received.

**Important:** GitHub Issues are public and generally require a GitHub account to post. Do **not** include passwords, API keys, identification documents, private conversations, confidential research data, or other sensitive personal information. For a privacy-related question, open an issue without sharing sensitive details and ask for a private contact channel.

Support is provided on a reasonable-efforts basis by the independent publisher, Gilad Shrem. The plugin has no external service or server operated by the publisher.

See the [privacy policy](PRIVACY.md) and [terms of use](TERMS.md).
