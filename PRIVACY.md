# Privacy Policy – LaTeX & LyX Label Generator

**Effective date:** October 30, 2026  
**Publisher:** Gilad Shrem

## Plugin operation

LaTeX & LyX Label Generator is an instruction-only skill for supported AI applications such as ChatGPT. It has no publisher-operated server, account system, telemetry, analytics, cookies, external API, or database.

## Data collected through the plugin

The publisher does not directly receive, collect, or store chat content, LaTeX documents, generated labels, account information, or usage history through the plugin. The skill uses the content the user chooses to provide in the host application for the purpose of generating labels. It does not independently transmit that content to the publisher.

## Platform processing and recipients

Content and account information entered in ChatGPT or another host application are processed by that platform under its own terms, privacy policy, and settings. For ChatGPT, see [OpenAI's Privacy Policy](https://openai.com/policies/privacy-policy/). The publisher has no independent copy of users' plugin interactions.

## Support data

If you open an issue in this project's [GitHub Issues](https://github.com/gshrem/latex-lyx-label-generator/issues), the issue content and publicly associated GitHub profile information may be visible to the publisher and the public. This information is used to respond to support questions and improve the skill, not for advertising or profiling. GitHub processes this information according to [GitHub's Privacy Statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement).

## Retention and user choices

The publisher does not retain plugin inputs, so there is no publisher-controlled retention period for those inputs. Users control their conversations according to the host platform's available settings and policies. Public support issues may remain available for as long as this project's GitHub repository is maintained, unless removed earlier. You may edit your own issue content using GitHub's controls or request that the publisher remove an issue through the [support page](SUPPORT.md). GitHub may retain data independently under its policies.

## Privacy contact

For privacy-related requests, consult the [support page](SUPPORT.md). Please do not place sensitive personal information in public GitHub issues.
